Setup

The quickstarts use Ubuntu 26.04 LTS on amd64. Install the tools on the machine where you will run the walkthrough.

On Ubuntu, Quick Start can install Git, Go and dotx together. Use the official links below to install tools individually.

Requirements

Install the tools your walkthrough uses.

Tool When you need it Official installation

CA certificates

For verified HTTPS downloads during installation.

Ubuntu CA certificates package

Git

To fetch DOT-CLI and DOT-Repository. Your GitHub account needs read access to both private repositories.

Git on Linux

Go

To build dotx from GitHub. Requires Go 1.27.2 or newer. An older installation can fetch the required toolchain with automatic toolchain selection.

Install Go

Docker Engine

For both Docker quickstarts. The first-composition guide requires access to Docker Engine 28 or later.

Docker Engine on Ubuntu

Docker Compose plugin

For the single-DOT quickstart.

Docker Compose plugin on Linux

Bash

To run either quickstart’s shell commands.

Ubuntu Bash package

GNU Coreutils

For standard file and checksum commands in the quickstarts.

Ubuntu Coreutils package

curl

To query deployed services in both quickstarts.

Get curl

jq

To inspect JSON responses in the single-DOT quickstart.

Get jq

iproute2

Provides ss for checking the forwarded port in the first-composition guide.

Ubuntu iproute2 package

dotx

Follow Install from GitHub with Go for MARE Git credentials, GOPRIVATE and CLI version selection. Use the walkthrough’s pinned version for a reproducible run.
