Requirements

Use Ubuntu 26.04 LTS on amd64 for the documented walkthroughs. The table shows which tools each route needs and links to their official installation guides. Install them on the machine where you will run the commands.

Tools

Install the tools your walkthrough uses.

Tool When you need it Official installation

CA certificates

For verified HTTPS downloads during installation.

Ubuntu CA certificates package

Git

To fetch DOT-CLI and DOT-Repository. Your GitHub account needs read access to both private repositories.

Git on Linux

GitHub CLI (gh)

For authenticated installer downloads in Quick Start and reusable Git credentials. Optional when installing directly with Go and existing Git credentials.

GitHub CLI on Linux

Go

To build dotx from GitHub. Requires Go 1.27.2 or newer. An older installation can fetch the required toolchain with automatic toolchain selection.

Install Go

Docker Engine

For Hello World and the deployment tutorials. The first composition requires access to Docker Engine 28 or later.

Docker Engine on Ubuntu

Docker Compose plugin

For the Prometheus Compose tutorial and practical book lessons.

Docker Compose plugin on Linux

Bash

To run the terminal walkthroughs.

Ubuntu Bash package

GNU Coreutils

For file and checksum commands in the reproducible walkthroughs.

Ubuntu Coreutils package

curl

To query deployed service APIs.

Get curl

jq

To inspect JSON responses in the Prometheus Compose tutorial.

Get jq

iproute2

Provides ss for checking the forwarded port in the first-composition guide.

Ubuntu iproute2 package

Continue with dotx

Once your tools are ready, follow Quick Start to install dotx and run Hello World. For Git credentials, GOPRIVATE, version selection and catalogue pins, use Manual installation.

DOT-Design documentation for the MARE project. Source and issue tracking are available on GitHub.
