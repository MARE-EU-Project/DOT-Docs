Setup

These instructions cover Ubuntu 26.04 LTS. Install dotx on the machine where you will run it.

Prerequisites

Install Git and Go before installing dotx. If you already have either tool, skip its APT commands and run the version check.

Git

Git fetches the private DOT-CLI source. Use a GitHub account with read access to MARE-EU-Project/DOT-CLI and working Git credentials.

Ubuntu 26.04 LTS

APT package
sudo apt update &&
sudo apt install git
Verify
git --version

Go

Go builds and installs dotx. The current release needs a Go 1.27.2 or newer toolchain.

Ubuntu 26.04 LTS

Ubuntu 26.04’s golang-go package supplies Go 1.26, which can download a compatible toolchain automatically.

APT package
sudo apt update &&
sudo apt install golang-go
Verify
go version &&
go env GOTOOLCHAIN

auto is the standard setting for automatic toolchain selection. If the displayed Go version is below 1.27.2 and automatic downloads are disabled, run export GOTOOLCHAIN=auto in the same terminal before installing dotx.

dotx

Ubuntu 26.04 LTS

Follow Install from GitHub with Go to check Git access, configure GOPRIVATE for the install command, and install dotx in your local bin directory. Use the pinned example when a walkthrough specifies a release.

Runtime tools

Install the runtime your walkthrough uses. The Prometheus quickstart uses Docker Engine and Docker Compose.

Docker Engine

Ubuntu 26.04 LTS

Follow Install Docker Engine on Ubuntu. Check that your account can reach the Docker daemon.

docker info --format '{{.ServerVersion}}'

Docker Compose

Ubuntu 26.04 LTS

Docker’s APT installation includes the Compose plugin. If Docker Engine is already installed and Compose is missing, follow Install the Docker Compose plugin.

docker compose version
