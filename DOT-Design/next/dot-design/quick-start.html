Quick Start

On Ubuntu 26.04 LTS, have Git, GitHub CLI (gh) and Docker Engine installed. Docker must be running and accessible to your normal user. See Requirements for official installation links. Your GitHub account needs read access to DOT-CLI and DOT-Repository.

Sign in once

gh auth login --hostname github.com --git-protocol https --web
gh auth setup-git --hostname github.com

Install

The installer prepares missing Go and CA certificates and installs dotx into $HOME/.local/bin. Run it as your normal user; sudo is used only for missing system packages.

dotx run is a new source-build feature, absent from release 0.5.0. Until a release includes it, this command selects main explicitly. The installer’s default remains latest for released installations. 
set -o pipefail
gh api repos/MARE-EU-Project/DOT-CLI/contents/scripts/install.sh \
  -H 'Accept: application/vnd.github.raw+json' | CLI_VERSION=main bash
export PATH="$HOME/.local/bin:$PATH"

Run Hello World

dotx run hello-world

Expect Docker’s Hello from Docker! greeting followed by:

DOT completed successfully. Container removed; setup is ready.

The command uses the Hello-World DOT from DOT-Repository and its pinned official Docker image. This upstream has no numbered release, so its definition is DOTs/external/Hello-World/dot.json, without a version directory. Inside an existing catalogue checkout it uses that checkout; otherwise gh retrieves only the definition from GitHub, without cloning or caching the catalogue. The first run downloads the image if it is not already present. The container is removed automatically; no cleanup command is needed.

If GitHub reports 404, check gh auth status and repository access. If Docker reports permission denied or cannot connect, follow its official installation and post-installation instructions. A failed run returns nonzero and does not print the success message. If a local checkout lacks Hello-World, update it.

Next: Run your first composition with Node Exporter and Prometheus. For manual installation and reproducible version pins, see Install with Go.
